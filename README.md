# 🛍️ SportWear Store – eCommerce de Ropa Deportiva

## 📌 Descripción

**SportWear Store** es una aplicación web de comercio electrónico enfocada en la venta de ropa deportiva. Este proyecto está desarrollado utilizando tecnologías base del frontend: **HTML, CSS y JavaScript**, con el objetivo de ofrecer una experiencia de usuario fluida, moderna y responsive.

Permite a los usuarios explorar productos, filtrarlos, agregarlos al carrito y simular una compra.

---

## 🚀 Características

- 🧥 Catálogo de productos deportivos
- 🔎 Búsqueda y filtrado por categorías
- 🛒 Carrito de compras dinámico
- 💰 Cálculo automático del total
- 📱 Diseño responsive (adaptable a móviles)
- ⚡ Interacciones dinámicas con JavaScript
- 🎨 Interfaz moderna con CSS

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – Estructura de la aplicación
- **CSS3** – Estilos, layout y responsive design
- **JavaScript (ES6+)** – Lógica, eventos y manipulación del DOM
